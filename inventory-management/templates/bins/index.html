How Bin Management Works
What are Bins?
  • Bins are specific storage locations within a warehouse/location
  • Examples: A1, B2, Shelf-3, Bay-12, etc.
  • Use bins for precise inventory tracking in large warehouses
  • Optional: You can store items at the location level without bins
Quick Steps
  1. Filter: Select a location from the dropdown above
  2. View: See all inventory in that location
  3. Assign: Choose a bin from each item's dropdown
  4. Move: Click the "Move" button to assign
Need to create bins? Go to Locations → Select a location → Click "Manage Bins" to add new bins.
