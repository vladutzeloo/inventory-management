Important Notes
  • Location Must Exist: The location code must already exist in the system. Create locations first before importing bins.
  • Duplicate Bins: If a bin with the same code already exists in the location, it will be updated with the new data from the file.
  • New Bins: Bins that don't exist will be created as new entries.
  • Bin Code Uniqueness: Bin codes must be unique within each location, but can be reused across different locations.
  • Case Handling: Location codes and bin codes are automatically converted to uppercase.
  • Empty Rows: Empty rows in the file will be automatically skipped.
Pro Tips
  • Export First: Export your current bins as a backup before large imports
  • Test First: Try importing a small sample file first to verify the format
  • Naming Convention: Use consistent bin naming conventions (e.g., A-01, A-02, B-01)
  • Batch Import: Import all bins for a location at once for efficiency
  • Descriptions: Use descriptions to help users locate bins physically
