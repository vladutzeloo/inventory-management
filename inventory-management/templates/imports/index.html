Excel File Format

Your Excel file should have the following columns (in order):

Column Description Example Required
A: Type material or item material Yes
B: Name Material/Item name Steel Plate 5mm Yes
C: Category Category name Metals No
D: Provider/Client Provider (materials) or Client (items) ABC Suppliers No
E: Location Location code (must exist) WH-01 Yes
F: Bin Bin code (auto-created if doesn't exist) A-01 No
G: Quantity Stock quantity 150.5 Yes
H: UOM Unit of measure KG No (defaults to PCS)
I: Cost Cost per unit 25.50 No (defaults to 0)
J: Batch Number Unique batch identifier (auto-generated if empty) BATCH-MAT-001 No
K: Supplier Batch/IO Number Supplier Batch for materials / Internal Order for items SUP-12345 or IO-2025-001 No
L: Diameter Diameter dimension 10.5 No
M: Width Width dimension 100 No
N: Length Length dimension 200 No
O: Height Height dimension 50 No
Auto-Creation Features:
  • Materials/Items will be created if they don't exist
  • Categories will be auto-created with the correct type
  • Providers/Clients will be auto-created
  • Bins will be auto-created in the specified location
  • Stock will be added to existing inventory levels
Important Notes:
  • Locations must exist before import - create them first!
  • Row 1 should be headers (will be skipped)
  • Empty rows will be skipped
  • Errors will be shown after import completes
