Import Instructions
Steps to Import
  1. Download the Excel template using the button below
  2. Fill in your item data following the template format
  3. Save the file in Excel format (.xlsx or .xls)
  4. Upload the completed file using the form
Important Notes
  • Do not modify the header row
  • Item Name and Unit of Measure are required
  • Existing items will be updated based on name
  • Active column accepts: Yes/No, True/False, 1/0
  • Empty rows will be skipped automatically
