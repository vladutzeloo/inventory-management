Important Notes
  • Duplicate Materials: If a material with the same name already exists, it will be updated with the new data from the file.
  • New Materials: Materials that don't exist will be created as new entries.
  • Batch Creation: To create a batch during import, you must provide: Batch Number, Location Code, Quantity, and Cost per Unit. The batch will only be created if it doesn't already exist and the location is valid.
  • Duplicate Batches: If a batch with the same batch number already exists, it will be skipped to prevent duplicates.
  • Location Validation: The Location Code and Bin Code must exist in your system before importing. Invalid locations will cause the batch creation to be skipped.
  • Data Validation: The system will validate all data. Rows with errors will be skipped and reported in the results.
  • Column Order: Keep the column order as shown in the template for best results.
  • Empty Rows: Empty rows in the file will be automatically skipped.
  • File Size: Keep file size under 10MB for optimal performance.
  • Backup Recommended: Consider exporting your current materials before importing to have a backup.
Pro Tips
  • Test First: Try importing a small sample file first to verify the format
  • Use Categories: Consistent category names help with filtering and reporting
  • Standard UoM: Use standard unit abbreviations (PCS, KG, LT) for consistency
  • Set Reorder Levels: Include reorder levels to enable low stock alerts
  • Review After Import: Always review the imported materials list after import
  • Export Before Import: Export your current materials as a backup before large imports
